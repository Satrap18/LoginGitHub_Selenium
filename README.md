# فایل README.md برای پروژه GitHub Login با Selenium

## توضیحات پروژه
این پروژه یک اسکریپت پایتون است که با استفاده از کتابخانه Selenium و Tkinter، یک رابط کاربری ساده برای ورود به حساب GitHub ایجاد می‌کند.

## ویژگی‌ها
- رابط کاربری گرافیکی ساده با Tkinter
- ورود خودکار به حساب GitHub با استفاده از Selenium
- امکان ذخیره مسیر chromedriver به صورت خودکار
- پنجره مرورگر پس از اجرا بسته نمی‌شود (برای بررسی روند کار)

## پیش‌نیازها
برای اجرای این پروژه نیاز به نصب موارد زیر دارید:

- پایتون 3.x
- کتابخانه‌های مورد نیاز:
  ```
  pip install selenium
  pip install tkinter
  ```

## نصب و راه‌اندازی
1. ابتدا پیش‌نیازهای بالا را نصب کنید.
2. فایل `chromedriver.exe` را دانلود و در مسیر پروژه قرار دهید.
3. فایل `main.py` را اجرا کنید:
   ```
   python main.py
   ```

## نحوه استفاده
1. پس از اجرای برنامه، یک پنجره کوچک با عنوان "Login GitGub" ظاهر می‌شود.
2. نام کاربری یا ایمیل خود را در فیلد اول وارد کنید.
3. رمز عبور خود را در فیلد دوم وارد کنید.
4. روی دکمه "Login!" کلیک کنید.
5. برنامه به صورت خودکار مرورگر Chrome را باز کرده و مراحل ورود به GitHub را انجام می‌دهد.

## نکات مهم
- این برنامه فقط برای مقاصد آموزشی است.
- از وارد کردن اطلاعات حساس در برنامه‌های آزمایشی خودداری کنید.
- برای استفاده در سیستم‌های مختلف، ممکن است نیاز به تنظیم مسیر chromedriver داشته باشید.
